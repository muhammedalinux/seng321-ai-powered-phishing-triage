## Mapping conventions
US/EN = existing product backlog IDs; TC/QM = existing QA test/metric IDs. Issue references are documentation work, not implementation tickets. Screen and Flow numbers refer to UI/UX and user-flows documents. Architecture references are component or diagram labels; N/A means no direct UI requirement. Mapped means relevant references identified, not approved; Partial means missing coverage; Conflict means contradictory design; Gap means no explicit mapping. NFR verification without TC/QM is a planned method, not an invented test ID.
